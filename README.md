# 라이프밀 인수인계

라이프밀 브랜드 업무 인수인계 문서. 여러 사람이 동시에 열어 수정하면 바로 반영됩니다.

- 배포 주소: https://miraclead2026.github.io/lifemeal-handover/
- 테스트 주소: https://miraclead2026.github.io/lifemeal-handover/?test (경로 `/handover_test` 사용, 운영 데이터와 분리)
- 구조: 단일 `index.html` (바닐라 JS), 빌드 없음
- 저장소: Firebase Realtime Database, 프로젝트 `lifemeal-md-board` (MD 프로모션 보드와 같은 프로젝트), 경로 `/handover`, 익명 로그인

## 보안 방식

- 문서 전체(홈, 파트 02~10, 계정·비밀번호)를 마스터 비밀번호로 브라우저 안에서 암호화(AES-GCM, PBKDF2 31만 회)한 뒤 저장합니다. Firebase와 GitHub에는 암호문만 올라갑니다.
- 저장 경로 이름도 마스터 비밀번호에서 만들어지므로, 비밀번호를 모르면 데이터 위치도 알 수 없습니다.
- 마스터 비밀번호는 어디에도 저장되지 않습니다. 잃어버리면 복구할 수 없으니 홈의 "백업 내보내기"로 주기적으로 백업하세요. 백업 파일은 암호화되지 않은 상태이므로 공유 폴더에 두지 않습니다.
- 20분 동안 사용하지 않으면 자동으로 잠깁니다.

## 처음 배포하기

1. GitHub에서 `miraclead2026/lifemeal-handover` 저장소를 만들고 `index.html`, `README.md`를 올립니다.
   - `lifemeal-handover-seed.json`은 암호화되지 않은 원본이므로 저장소에 올리지 않습니다.
2. 저장소 Settings > Pages > Branch를 `main` / `(root)`로 저장합니다. 1~2분 뒤 배포 주소가 열립니다.
3. Firebase 콘솔 > `lifemeal-md-board` > Realtime Database > 규칙에 아래 "보안규칙" 항목을 추가하고 게시합니다.
4. 배포 주소를 열고 마스터 비밀번호(8자 이상)를 입력합니다. "이 비밀번호로 된 문서가 없습니다" 화면에서 같은 비밀번호를 한 번 더 입력하고, `lifemeal-handover-seed.json`을 선택한 뒤 "새 문서 만들기"를 누릅니다.
5. 문서가 열리면 seed 파일은 삭제해도 됩니다.

## 보안규칙

기존 규칙의 `"rules": { ... }` 안에 아래 두 항목을 추가합니다. 기존 `mdboard` 규칙은 그대로 둡니다.

```json
"handover": {
  "$room": {
    ".read": "auth != null && $room.length === 32",
    ".write": "auth != null && $room.length === 32"
  }
},
"handover_test": {
  "$room": {
    ".read": "auth != null && $room.length === 32",
    ".write": "auth != null && $room.length === 32"
  }
}
```

`handover` 자체에는 읽기 권한을 주지 않으므로, 경로 이름을 모르면 목록을 볼 수 없습니다. 루트에 `".read": true` 같은 테스트 모드 규칙이 남아 있으면 이 제한이 적용되지 않습니다(내용은 여전히 암호화되어 있음).

## 편집 방법

- 홈: 작성자, 인수자, 인계일은 바로 입력하면 저장됩니다. "홈 편집"에서 핵심 숫자, 자주 쓰는 주소, 문서 제목을 고치고 파트를 추가합니다.
- 파트: 상단 "편집" → 묶음별로 제목, 설명, 항목을 고친 뒤 "적용". 파트 순서 변경과 삭제도 편집 화면 아래에 있습니다.
- 항목 입력 규칙 (한 줄에 한 항목)
  - `1. ` 로 시작: 번호가 붙는 단계
  - 앞에 공백 두 칸: 바로 위 항목의 하위 항목
  - `!` 로 시작: 주의 문구 상자
  - `**굵게**`: 굵은 글씨
  - 주소(예: `lifemeal.imweb.me`)는 자동으로 링크, `#1B4D3E` 같은 색상 코드는 색 견본이 붙습니다.
- 계정·비밀번호: "계정 추가" 또는 각 줄의 "편집". 비밀번호를 입력하면 상태가 자동으로 "확인 필요"로 바뀝니다.
- 마스터 비밀번호 변경: 계정·비밀번호 파트 상단. 문서 전체를 새 비밀번호로 다시 암호화해 옮깁니다. 변경 후 다른 사람에게 새 비밀번호를 따로 전달합니다.

## 동시 편집

- 수정은 누르는 즉시 저장되고 다른 사람 화면에 바로 반영됩니다.
- 같은 파트를 두 사람이 동시에 편집하면 나중에 "적용"한 쪽 내용이 남습니다. 편집 중에 다른 사람의 변경이 들어오면 화면 아래에 안내가 뜨고, 편집을 마치면 최신 내용으로 다시 표시됩니다.
